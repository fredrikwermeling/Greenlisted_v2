Updates

2026

On a phone

The app works on a phone. Settings fold into headings you tap to open, the output section offers the oligo list with the rest one tap away, popouts hold the page still behind them, and the library-overlap plot is drawn to fit the screen. Copy-number data is fetched only when a run needs a number, with the download shown as it arrives. Validate sgRNA still works better on a computer, where a wide table can be read.

Spelling suggestions

Symbols not found now suggests the closest names in the selected library — To53 offers TP53, CDNK2A offers CDKN2A. Press one to put it in the gene box, or take the first suggestion for every symbol at once.

Which other libraries pick the same guide

A Libraries button and a Found in other libraries column on each guide say how many other libraries of the same species chose that sgRNA. A guide several independent designs arrived at has passed several scoring schemes, which is a useful second opinion when deciding what to order. The count leaves out the library you are designing from.

Genomic context for primer design

A Context button on each guide fetches the sequence 500 bp either side from the UCSC Genome Browser and marks the spacer, PAM, predicted cut site, exons and repeats — what you need to design primers for checking an edit. The flank length is adjustable.

From there: Open in Primer-BLAST starts NCBI Primer-BLAST with the sequence and the primer windows filled in, sized for Sanger (ICE/TIDE) or amplicon NGS; Copy as text, Download FASTA and Download GenBank take the sequence out (the GenBank file opens in SnapGene or Benchling with its features intact); Export image saves the figure as PDF, SVG, PowerPoint, PNG or TIFF at a width you choose; and Export for AI writes a .json of the guide, its locus and — if you paste in the Primer-BLAST results — every candidate pair measured against the cut site, to hand to an assistant.

Methods text for your manuscript

A Methods text row in section 4 writes a Materials & Methods description of the run you just made: a sentence for the main text, a fuller paragraph, and the references for the software and the library. It describes only what the run actually did — check it against your final protocol.

Downloads

Each output has one Download button that asks for the format: comma- or tab-separated text, or an .xlsx workbook. Choose the workbook if you will open it in Excel — a text file lets Excel rewrite gene symbols, so MARCH1, SEPT9 and DEC1 become dates. Everything at once is offered as a .zip or as one workbook with a sheet per output.

Better synonym matching

The synonym tables were rebuilt from HGNC and MGI. Matching now checks that a symbol and its match are the same gene, so a search is no longer answered with a different gene that once shared the name: about 1 300 more symbols resolved, and wrong matches down by 93%.

Curated gene lists

A Curated lists… link fills the gene box with a ready-made set — cancer genes, kinases, transcription factors, DNA repair, cell surface, the druggable genome, GPCRs, ion channels and others — for human or mouse, each drawn from a published source named on its row and checked against the built-in libraries. Add several and duplicates are dropped. They are starting points to edit down, not definitive gene families.

Control sgRNAs

A Controls box in section 3 adds control guides to your library, so you no longer merge them in by hand. Tick a type and it fills in a suggested number you can edit; guides are drawn at random per run and added after ranking.

Safe-targeting (CutCtrl) — one cut in a gene desert, so they carry the same DNA-damage cost as a real guide and make the more honest baseline.

Non-targeting (NegCtrl) — no match in the genome. A useful second check, but they never cut, so they flatter the baseline.

Essential genes — positive controls that should drop out if the screen worked. Three by default (RAN, RPS8, PLK1), up to nine.

Libraries that ship without a control type borrow it from Jacquere or Julianna, matched to the species, and the run summary names the donor.

Copy number for human cell lines

Pick a human cell line in section 3 and the run gains a copy-number column and a per-gene copy-number file: deep deletions, where the gene is effectively absent and its guides report nothing, and amplifications, where Cas9 cuts once per copy and the cell can drop out regardless of gene function — a classic false positive, as with MYCN in IMR-32.

The same data answers a lookup of its own, from the Copy number (human) button at the top: any list of genes across any of the ~1 900 DepMap lines, as the relative value and as an estimated copy count using the line’s ploidy. Source: DepMap OmicsCNGene (24Q4), restricted to genes at least one built-in library can target.

Library overlap

A Library overlap button shows an UpSet plot of how sgRNA sequences are shared across the built-in libraries, human and mouse, so you can see which libraries carry unique content.

Validate sgRNA

Paste any number of sgRNA sequences and find which libraries they come from, with the gene symbol, gene ID and available on- and off-target scores. The index covers widely used knockout libraries from Addgene and the Broad Institute GPP — Brunello, Brie, GeCKO v2, Gattinara, Gouda, Jacquere, Julianna, VBC, Yusa, TKOv3, mTKO and MinLibCas9 — with separate indices for human and mouse.

Jacquere (human) and Julianna (mouse) libraries

Two new libraries from the Broad Institute/John Doench lab, designed with the latest on- and off-target scoring (RS3 and CFD), replacing Brunello and Brie as the recommended libraries. Drepanos LM et al. Balancing off-target and on-target considerations for optimized Cas9 CRISPR knockout library design. bioRxiv 2025. doi: 10.1101/2025.08.26.672375 (preprint).
