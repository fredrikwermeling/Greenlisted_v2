The test version says so

A copy of the app served from anywhere other than greenlisted.cmm.se now carries a banner saying it is a test version, and its browser tab reads Green Listed (test). Nothing has to be switched on or off when a version is copied to the live site: the app reads the address it was served from and decides for itself.

The rule is deliberately the wrong way round — only the live address counts as live, so any other copy declares itself rather than quietly passing for the real thing.

Smaller things

When genes come from a Curated lists… entry, a line above Symbols not found names the list and where it came from, and the methods text in section 4 says the same — “The target genes were taken from a curated list supplied with the software: 1230 genes of the Cancer genes list (OncoKB Cancer Gene List)”. If you then edit the box, the count follows what is actually left in it rather than claiming the whole list.

The panel headings are a little shorter, the library dropdown having been sized down to them rather than the other way round, and Symbols not found lines up with Pick human cell line beside it in every state. The adapter preview used to appear only once an adapter was typed, which shifted everything below it; it now stays put and says what it is for until there is something to show.

A rule separates the matching options from the box the genes go in, which previously read as a third matching option. The symbol box explains the four steps until you type in it, and gene symbols can now be pasted in whatever shape they arrive — one per line, comma separated out of a spreadsheet, semicolons, tabs or plain spaces, in any mixture. Pressing Update tidies whatever you pasted into one per line. The same applies to the sgRNA sequences in Validate sgRNA.

The cursor starts in the symbol box, so you can type genes straight away. The logo uses the original artwork again, so the name, the v2.0 and the leaves are the drawn shapes rather than a reconstruction of them; only the strapline is set as text, in the place the old one occupied. It is no longer a link. The heading above it said “Symbols” directly under a section called “2. Input symbols”, with a second information dot a few pixels from the first; it now reads Matching and belongs to the three matching options under it, which is what its explanation was always about.

The three column headings are the same height again. One holds a dropdown and the others hold a line of text, so they had drifted out of step.

Curated lists offer only Add. The box starts empty, so adding to an empty box is what Replace did, and duplicates are dropped either way.

American spelling throughout.

Which other libraries pick the same guide

A Libraries button beside Context on each guide, and an Other libraries column beside it, say how many other libraries of the same species also chose that sgRNA. A guide several independent designs arrived at has passed several different scoring schemes, which is a useful second opinion when deciding what to order.

The comparison is within one species and leaves out the library you are designing from, so a count of 2 of 7 means two of the seven other human libraries. It reads the same index the Validate sgRNA tool searches, built from the guide lists distributed via Addgene and the Broad Institute GPP portal, which covers several published libraries the app does not itself offer. That index is about 35 MB per species, so it loads only when you ask for it — the column offers a link rather than fetching it after every run.

Genomic context for primer design

Each guide in the Oligos to order and Full output views now has a Context button. It fetches the genomic sequence 500 bp either side of that sgRNA from the UCSC Genome Browser (hg38 or mm39) and shows it with the spacer, PAM, predicted Cas9 cut site and RefSeq Select exons marked — what you need to design PCR primers for checking an edit by Sanger sequencing (ICE, TIDE). The flank length can be changed, and the view can be flipped between guide and gene orientation.

The sequence can be taken out four ways, chosen for what survives a paste: Copy with colors keeps the coloring, for a paste into a document, an e-mail or a slide; Download FASTA writes plain text with the flanks in lower case and the spacer in upper case, positions in the header; Download GenBank writes a file with the exon, spacer, PAM and cut-site features that opens directly in SnapGene or Benchling; and Open in Primer-BLAST starts NCBI Primer-BLAST with the sequence filled in, the specificity check set to the genome of the guide's species, and the primer windows worked out from the flank so both primers stay at least 150 bp clear of the cut, giving an amplicon of at least 500 bp. Change the flank and the windows follow; the panel shows the range being sent and warns if the sequence is too short to design primers in. It also raises the product-size ceiling from 1000 bp to the length of the window, so a pair may span all of it. Open in Primer-BLAST takes you to its own form with everything filled in; it pauses once to ask which genome hit is your target, so tick the row for your gene and press Submit. Your own Primer-BLAST settings (windows, product size, Tm, primer length and so on) can be entered once and are remembered.

A Primers for choice above the buttons switches the whole design between the two ways of reading an edit: Sanger — ICE / TIDE keeps the primers at least 150 bp clear of the cut and asks for a product of 500 bp or more, while Amplicon NGS asks for a 180–280 bp product with 50 bp of clearance, sized to fit inside a 2×150 paired-end read with the cut near the middle. Editing any of the underlying numbers switches it to custom.

An Export for AI button writes a .json holding the guide, its locus, the annotated sequence and — if you paste in the CSV from Primer-BLAST’s Download primer pairs — every candidate pair re-expressed as its distance from the cut site, with a verdict against the ICE and TIDE guidance. Attach it to an assistant and ask which pair to order. Primer-BLAST is still what designs and specificity-checks the primers; the file exists so the choice between its candidates can be made with the cut site, the exon and the read length in view. It checks that the pasted results really came from the sequence on screen, since the flank is adjustable and positions from a different flank line up with nothing.

An Export image button saves the annotated sequence as a figure in PDF, SVG, PowerPoint, PNG or TIFF, at a width and resolution you choose — the same set of formats as the charts in Correlate. The figure is drawn as vector artwork rather than captured from the screen, so the three vector formats stay sharp at any zoom and come out a few kilobytes rather than a megabyte: a PDF of a 1 kb window is about 9 KB, and its sequence is real selectable text.

The guide is located by searching for the spacer within the gene, so it works for every library, including those without coordinates. Genes that Jacquere and Julianna list under a combined label, such as ACE|nan or Timm10b|Gm45799, are resolved to the real symbol — about 2 950 genes across those two libraries that previously reported “not found”. The same labels were inflating the gene counts shown in Library overlap, because a gene listed both plainly and inside a combined label counted twice: Jacquere reads 19 714 genes rather than 20 275, and Julianna 20 963 rather than 22 267. The overlap bars themselves are unaffected — they compare sgRNA sequences, not gene names. On demand only — one guide per click, nothing is fetched during a design.

Methods text for your manuscript

A new Methods text row in section 4 writes a Materials & Methods description of the run you just made: a one-sentence version for the main text, a fuller paragraph for a detailed or supplementary section, and the references for the software and for the library you used. Copy it straight into a manuscript, or download it with the other outputs.

It describes only what the run actually did, so an option you left off produces no sentence. Check it against your final protocol before submission.

One Download button per output

Each output in section 4 now has a single Download button that asks which format you want, rather than a separate link per format — the format is a detail of saving, not a different result.

The delimited outputs are written as comma-separated .csv files rather than tab-separated .tsv, so they open directly in Excel and other spreadsheet software. Any field containing a comma is quoted, so nothing is lost on the way in. If you plan to open a result in Excel, choose the .xlsx workbook — it is the only format that stops gene symbols being read as dates.

Excel downloads

Every output in section 4 is now offered in two formats side by side, labeled by extension: the text file that MAGeCK and other tools read, and an .xlsx workbook. There is the same pair for everything at once — a .zip of the text files, or one workbook with a sheet per output.

Use the workbook if you plan to open the result in Excel. Opening a text file lets Excel rewrite gene symbols, so MARCH1, SEPT9 and DEC1 become dates and an alias such as 2E4 becomes 20 000. Nothing inside a .csv or .tsv can prevent that, but in a workbook the cell types are already set, so symbols arrive intact while scores stay numeric and sortable. Note that Brunello, VBC and GeCKO v2 still use the pre-2020 symbols, while Jacquere, Julianna and Gattinara carry the current ones (MARCHF1, SEPTIN9) that HGNC introduced to end this problem.

Better synonym matching

The synonym tables were rebuilt from HGNC and MGI, adding several thousand recently renamed genes and proper human–mouse orthologue links. Matching now checks that a symbol and its match are the same gene, so a search is no longer answered with a different gene that once shared the name — across all pairs of built-in libraries this resolves about 1 300 more symbols while cutting wrong matches by 93%.

Curated gene lists

A Curated lists… link beside Load test data fills the symbol box with a ready-made gene set: cancer genes, kinases, phosphatases, transcription factors, DNA damage response & repair, cell surface, CD markers, the druggable genome, FDA-approved drug targets, GPCRs, ion channels, transporters or proteases. Replace what is in the box or add to it — duplicates are dropped, so classes can be combined. Lists are available for human and mouse, and the picker shows the set matching your selected library.

Each list is drawn from a published, curated source, named on its row in the picker: the Human Protein Atlas, UniProt, HGNC, MGI, OncoKB, the in silico human surfaceome (Bausch-Fluck et al., PNAS 2018) and Lambert et al. 2018 for the transcription factors. The cell surface list covers surface-exposed proteins, so membrane-anchored proteins facing the cytoplasm are excluded. Every symbol is checked against the built-in libraries for that species, so a list only ever suggests genes at least one library can target.

These are starting points to edit down, not definitive gene families.

Control sgRNAs

A new Controls box in section 3 adds control guides to your designed library, so you no longer have to search for them by hand and merge the files yourself.

Safe-targeting (CutCtrl) — one cut site in a gene desert. These carry the same DNA-damage cost as a real guide, so they make the more honest baseline and take the larger share when both types are added. Jacquere and Julianna hold 900, Gattinara and Gouda 500.

Non-targeting (NegCtrl) — no match anywhere in the genome. A useful second check, but they never cut, so they flatter the baseline. In every built-in library except VBC.

Essential genes — positive controls that should drop out strongly if the screen worked. Three by default (RAN, RPS8, PLK1, spanning nuclear transport, the ribosome and mitosis), up to nine.

Borrowed controls. Not every library ships both control types: VBC human and mouse carry none at all, while Brunello, Brie and both GeCKO v2 libraries carry non-targeting controls but no safe-targeting ones. Ticking a type the selected library lacks now takes those guides from Jacquere or Julianna, matched to the species, and the run summary names the donor beside the type it supplied. Only guides that suit the host library are used: every VBC spacer begins with G, so borrowed guides that do not are left out — which leaves 235 safe-targeting and 26 non-targeting to draw on for human, and 248 and 27 for mouse. The panel reports the number when it is below the suggested amount.

Ticking a type fills its box with a suggested number you can edit. A focused library has no neutral majority of no-effect genes to borrow a baseline from, so its controls have to define it — the suggestion is a total shared between the two spike-in types, and grows with how many genes you screen and how many sgRNAs each one has. Guides are drawn at random on each run and added after ranking, so “limit to top” does not thin them. Hover the i beside Controls for the reasoning.

Copy-number warnings in the sgRNA output

Pick a human cell line in section 3 and the Oligos to order file gains a Copy-number warning column. Only the extremes are flagged, so it holds nothing but things worth acting on: deep deletions (CN < 0.3), where the gene is effectively absent and its guides report nothing, and amplifications (CN ≥ 3.0), where Cas9 cuts once per copy so the cell takes many simultaneous breaks and can drop out regardless of gene function — a classic false positive, as with MYCN in IMR-32 at ~22 copies. Genes with ordinary copy number get a blank cell, and the column only appears when a cell line is selected.

Copy number for human cell lines

A new Copy number (human) feature uses DepMap’s gene-level copy-number data to inform CRISPR screen design. Dataset: DepMap’s OmicsCNGene (24Q4 release); the gene list is restricted to genes targetable by at least one of the built-in CRISPR libraries, since those are the genes you can actually screen. The feature has two complementary ways to use it:

1. Dedicated copy-number search. Pick one or more human cell lines from the ~1 900-line DepMap catalog and look up the relative copy number of any list of genes. Results show both the raw CN value (relative to each line’s genome-wide baseline) and an estimated actual copy count per cell, rescaled using the line’s measured ploidy. Reached from the “Copy number (human)” button at the top of the app.

2. Copy number integrated into the sgRNA search. In section 3 of the regular sgRNA flow, optionally pick one human cell line. The screening output will then include a per-gene copy-number file alongside the regular Full / Adapters / MAGeCK outputs. Useful for flagging genes that are heavily amplified (potentially harder to knock out) or already deleted (likely not screenable) in the line you plan to screen.

Library overlap visualization

A new “Library overlap” button shows an UpSet plot of how sgRNA sequences are shared across all built-in CRISPR libraries, for both human and mouse. This makes it easy to see which libraries have unique content and where sequences overlap.

Validate sgRNA feature

A new validation tool that lets you search any number of sgRNA sequences and find whether they are present in any of the embedded libraries. The validation index includes top-ranked sgRNAs from several widely used CRISPR knockout libraries sourced from Addgene and the Broad Institute GPP, including Brunello, Brie, GeCKO v2, Gattinara, Gouda, Jacquere, Julianna, VBC, Yusa Human v1, Yusa Mouse v2, TKOv3, mTKO, and MinLibCas9. The tool returns the matched gene symbol, library name, gene ID, and available on-target/off-target scores for each sequence. Separate indices are available for human and mouse libraries.

Jacquere (human) and Julianna (mouse) libraries

Added two new CRISPR knockout libraries from the Broad Institute/John Doench lab, designed with the latest on-target and off-target scoring (RS3 and CFD). These libraries replace Brunello and Brie as the recommended next-generation libraries for human and mouse screens, respectively. See Drepanos LM et al. Balancing off-target and on-target considerations for optimized Cas9 CRISPR knockout library design. bioRxiv 2025. doi: 10.1101/2025.08.26.672375 (link to preprint).
