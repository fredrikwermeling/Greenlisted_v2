Updates

2026

Use on a phone

The app is updated for use on a phone. Settings and results fold into headings you tap to open, and the layout fits a small screen. Validate sgRNA still works better on a computer, where a wide table can be read.

Spelling suggestions

When a gene symbol matches nothing, the app suggests the closest names in the selected library. Press one to put it in the gene box.

Which other libraries pick the same guide

Each guide shows how many other libraries of the same species contain the same sgRNA. A guide that several independent designs arrived at has passed several scoring schemes, which is a useful second opinion when deciding what to order.

Genomic context for primer design

A Context button on each guide fetches the sequence 500 bp either side from the UCSC Genome Browser and marks the spacer, PAM, predicted cut site, exons and repeats. The flank length is adjustable.

From there you can open NCBI Primer-BLAST with the sequence and primer windows already filled in (sized for Sanger or for amplicon NGS), save the sequence as FASTA or GenBank, export the figure as PDF, SVG, PowerPoint, PNG or TIFF, or write a .json file to hand to an AI assistant when choosing between primer pairs.

Methods text for your manuscript

Section 4 writes a Materials and Methods description of the run you just made, with references for the software and the library. It covers only what the run actually did, so check it against your final protocol.

Downloads

Each output has one Download button that asks for the format: .csv, .tsv or an .xlsx workbook. Everything at once is available as a .zip of text files or as one workbook with a sheet per output.

Be aware that Excel converts some gene symbols to dates when it opens a .csv or .tsv file, so MARCH1, SEPT9 and DEC1 arrive as 1-Mar, 9-Sep and 1-Dec. The .xlsx workbook is not affected, so use it if you plan to work in Excel.

Better synonym matching

The synonym tables were rebuilt from HGNC and MGI. A symbol and its match are now checked to be the same gene, so a search is no longer answered with a different gene that once shared the name. About 1 300 more symbols resolve, and wrong matches are down by 93%.

Curated gene lists

A Curated lists… link fills the gene box with a ready-made set: cancer genes, kinases, transcription factors, DNA repair, cell surface, the druggable genome, GPCRs, ion channels and others, for human or mouse. Each list comes from a published source named in the picker and is checked against the built-in libraries. They are starting points to edit down, not definitive gene families.

Control sgRNAs

A Controls box in section 3 adds control guides to your library, so you no longer merge them in by hand. Safe-targeting guides (CutCtrl) cut once in a gene desert and carry the same DNA damage cost as a real guide, which makes them the more honest baseline. Non-targeting guides (NegCtrl) never cut. Essential genes are positive controls that should drop out if the screen worked, three by default (RAN, RPS8, PLK1).

Libraries that ship without a control type borrow it from Jacquere or Julianna, matched to the species, and the run summary names the donor.

Copy number for human cell lines

Pick a human cell line in section 3 and the run flags genes that are deeply deleted, where the guides report nothing, or amplified, where the many cuts cause excessive DNA damage that can bias the screen. A per-gene copy-number file is produced alongside the other outputs.

The Copy number (human) button looks up any list of genes across the roughly 1 900 DepMap cell lines, as a relative value and as an estimated number of copies. Data: DepMap OmicsCNGene, 24Q4.

Library overlap

A Library overlap button shows an UpSet plot of how sgRNA sequences are shared across the built-in libraries, human and mouse.

Validate sgRNA

Paste any number of sgRNA sequences and see which libraries they come from, with the gene symbol, gene ID and available on- and off-target scores. The index covers widely used knockout libraries from Addgene and the Broad Institute GPP, with separate indices for human and mouse.

Jacquere (human) and Julianna (mouse) libraries

Two new libraries from the Broad Institute/John Doench lab, designed with the latest on- and off-target scoring (RS3 and CFD), replacing Brunello and Brie as the recommended libraries. Drepanos LM et al. Balancing off-target and on-target considerations for optimized Cas9 CRISPR knockout library design. bioRxiv 2025. doi: 10.1101/2025.08.26.672375 (preprint).
