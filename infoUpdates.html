Updates

2026

Copy number for human cell lines / A new Copy number (human) feature uses DepMap’s gene-level copy-number data to inform CRISPR screen design. Two ways to use it:

  • Dedicated search — pick one or more human cell lines from the ~1 900-line DepMap catalogue and look up the relative copy number of any list of genes. Results show both the raw CN value (relative to each line’s genome-wide baseline) and an estimated actual copy count per cell, rescaled using the line’s measured ploidy.
  • Integrated with the sgRNA search — optionally pick one human cell line in section 3 and, in addition to the regular sgRNA outputs, get a per-gene copy-number file alongside. Useful for flagging genes that are heavily amplified (potentially harder to knock out) or already deleted (likely not screenable) in the line you plan to screen.
The dataset is DepMap’s OmicsCNGene (24Q4 release). The gene list is restricted to genes targetable by at least one of the built-in CRISPR libraries, since those are the genes you can actually screen.

Library overlap visualization / A new "Library overlap" button shows an UpSet plot of how sgRNA sequences are shared across all built-in CRISPR libraries, for both human and mouse. This makes it easy to see which libraries have unique content and where sequences overlap.

Validate sgRNA feature / A new validation tool that lets you search any number of sgRNA sequences and find whether they are present in any of the embedded libraries. The validation index includes top-ranked sgRNAs from several widely used CRISPR knockout libraries sourced from Addgene and the Broad Institute GPP, including Brunello, Brie, GeCKO v2, Gattinara, Gouda, Jacquere, Julianna, VBC, Yusa Human v1, Yusa Mouse v2, TKOv3, mTKO, and MinLibCas9. The tool returns the matched gene symbol, library name, gene ID, and available on-target/off-target scores for each sequence. Separate indices are available for human and mouse libraries.

Jacquere (human) and Julianna (mouse) libraries / Added two new CRISPR knockout libraries from the Broad Institute/John Doench lab, designed with the latest on-target and off-target scoring (RS3 and CFD). These libraries replace Brunello and Brie as the recommended next-generation libraries for human and mouse screens, respectively. See Drepanos LM et al. Balancing off-target and on-target considerations for optimized Cas9 CRISPR knockout library design. bioRxiv 2025. doi: 10.1101/2025.08.26.672375 (link to preprint).
