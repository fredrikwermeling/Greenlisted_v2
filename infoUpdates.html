Spike control sgRNAs into your library

A new Controls box in section 3 adds the built-in control sgRNAs to your designed library, so you no longer have to search for NegCtrl / CutCtrl by hand and merge the files yourself. Tick either kind, or both, and set how many of each:

Non-targeting controls. Sequences with no match anywhere in the genome. They control for the vector and the selection, but not for cutting. Available in every built-in library except VBC — 1000 in Brunello, Brie and both GeCKO v2 sets, 500 in Gattinara and Gouda, 100 in Jacquere and Julianna.

Safe-targeting controls. A single cut site in a gene desert, so they control for the DNA-damage response that any double-strand break provokes — something non-targeting guides cannot do. Available in Jacquere and Julianna (900) and in Gattinara and Gouda (500).

Essential-gene positive controls. Optionally add 1–9 core-essential genes, three by default, which drop out in virtually every proliferating line — so a screen that worked shows them strongly depleted. They are taken in a fixed order, not at random, because a positive control is only useful if you know what to expect from it and can compare across experiments. The default three span distinct processes, so a partial failure tells you which one did not respond rather than just that something went wrong. The rest are ordered by how rarely the gene is itself lost across the DepMap panel. POLR2A comes last deliberately: it sits beside TP53 on 17p13 and its copy number tracks TP53’s at r = 0.92, so across the 414 lines that have lost that region its mean CN is 0.62 against 0.92 overall — a positive control that is itself hemizygous in about a fifth of cell lines. PSMA1 was considered and dropped: Jacquere carries only one guide for it against three for everything else here. These are ordinary genes, so they are ranked and top-N sliced like any gene you type.

Leave a count blank for the automatic suggestion: 20% of the targeting guides in your output, clamped between 50 and 200 and capped at what the library holds. In a genome-wide screen the null distribution comes from the 85–90% of genes with no phenotype, which is why the built-in libraries all ship about 1000 controls regardless of size (0.8–2.4% of their guides) — those are a normalisation anchor rather than the null itself. A targeted library has no neutral majority to borrow from, since its genes were chosen precisely for their expected effect, so its controls must define the null themselves.

The 50 and 200 bounds come from what actually degrades when the control set is small. The null SD has to be estimated from the n controls, so the test follows a t distribution with n−1 degrees of freedom and its critical value sits above the ideal; and the control median doubles as the normalisation anchor, with a standard error of 1.25 SD / √n that adds noise to every gene-versus-control comparison. Combining the two, for three guides per gene and a Bonferroni correction over 500 genes, the effective detection threshold relative to an unlimited control set is 1.30× at n=25, 1.14× at n=50, 1.07× at n=100 and 1.03× at n=200. In other words 25 controls make a hit about 30% harder to call, while past 200 there is essentially nothing left to buy.

Spike-in controls are added after ranking, so “limit to top” thins each gene’s guides without thinning the control set, and the guides are drawn at random on each run rather than always taking the same ones. All controls appear in the Full, Adapters and MAGeCK outputs like any other entry.

Copy-number warnings in the sgRNA output

When you pick a human cell line in section 3, the Output with adapters file gains a Copy-number warning column flagging genes whose copy number makes them awkward to screen in that line. Only the extremes are flagged, so the column contains nothing but things worth acting on:

Deep deletion (CN < 0.3). The gene is effectively absent, so its guides cannot report a knockout phenotype and any signal from them is noise.

Amplification (CN ≥ 3.0). The copy-number effect. Cas9 cuts once per copy, so in an amplified region the cell takes many simultaneous double-strand breaks and can die from the damage regardless of what the gene does. That reads as dropout and is a classic false positive — e.g. MYCN in IMR-32 at ~22 copies, or EGFR in A-431 at ~18.

Genes with ordinary copy number get a blank cell, and the column only appears when a cell line is selected, so the file keeps its familiar three-column shape otherwise.

Copy number for human cell lines

A new Copy number (human) feature uses DepMap’s gene-level copy-number data to inform CRISPR screen design. Dataset: DepMap’s OmicsCNGene (24Q4 release); the gene list is restricted to genes targetable by at least one of the built-in CRISPR libraries, since those are the genes you can actually screen. The feature has two complementary ways to use it:

1. Dedicated copy-number search. Pick one or more human cell lines from the ~1 900-line DepMap catalogue and look up the relative copy number of any list of genes. Results show both the raw CN value (relative to each line’s genome-wide baseline) and an estimated actual copy count per cell, rescaled using the line’s measured ploidy. Reached from the “Copy number (human)” button at the top of the app.

2. Copy number integrated into the sgRNA search. In section 3 of the regular sgRNA flow, optionally pick one human cell line. The screening output will then include a per-gene copy-number file alongside the regular Full / Adapters / MAGeCK outputs. Useful for flagging genes that are heavily amplified (potentially harder to knock out) or already deleted (likely not screenable) in the line you plan to screen.

Library overlap visualisation

A new “Library overlap” button shows an UpSet plot of how sgRNA sequences are shared across all built-in CRISPR libraries, for both human and mouse. This makes it easy to see which libraries have unique content and where sequences overlap.

Validate sgRNA feature

A new validation tool that lets you search any number of sgRNA sequences and find whether they are present in any of the embedded libraries. The validation index includes top-ranked sgRNAs from several widely used CRISPR knockout libraries sourced from Addgene and the Broad Institute GPP, including Brunello, Brie, GeCKO v2, Gattinara, Gouda, Jacquere, Julianna, VBC, Yusa Human v1, Yusa Mouse v2, TKOv3, mTKO, and MinLibCas9. The tool returns the matched gene symbol, library name, gene ID, and available on-target/off-target scores for each sequence. Separate indices are available for human and mouse libraries.

Jacquere (human) and Julianna (mouse) libraries

Added two new CRISPR knockout libraries from the Broad Institute/John Doench lab, designed with the latest on-target and off-target scoring (RS3 and CFD). These libraries replace Brunello and Brie as the recommended next-generation libraries for human and mouse screens, respectively. See Drepanos LM et al. Balancing off-target and on-target considerations for optimized Cas9 CRISPR knockout library design. bioRxiv 2025. doi: 10.1101/2025.08.26.672375 (link to preprint).
