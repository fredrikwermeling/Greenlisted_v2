Copy number reference — pick cell line(s)

  • Gene-level copy number from DepMap — WGS where available, otherwise WES.
  • Values are relative to each line’s own genome-wide baseline: 1.0 = typical, ≥ 3.0 = amplification, ≤ 0.5 = deletion.
  • The results page rescales to estimated actual copy counts using each line’s measured ploidy.
  • More cell-line data: depmap.org or the cell line browser in Correlate (Green Listed’s sister app).
